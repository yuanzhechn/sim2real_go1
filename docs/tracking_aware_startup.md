# 可选跟踪感知起身（2026-10-17）

19499完成了30秒零速度站立，现场确认自行站稳、后膝盖离地且无明显振动。
随后重新起身时，右前小腿再次在进入策略前达到0.45rad跟踪限值，行走指令没有发出。
高电量下仍发生这一问题，不能归结为之前的低电压；根因尚未隔离。

原起身插值每个周期按时间推进。新增可选`--tracking-aware-startup`，必须配合`--soft-startup --startup-duration 16`：

- 预计下一目标与实际位置误差超过0.35rad时，保持上一目标，继续发送原PD增益。
- 实际位置与保持目标误差回落到0.30rad以内才恢复推进，目标不会为追赶时间跳步。
- 0.45rad硬跟踪限值、20Nm估计请求力矩限值及姿态、电池、速度、温度、急停保护保留。
- 最长28秒，无法到达默认姿态就抛出错误，由既有finally卸力并恢复原厂控制；不会进入策略。
- 这是待实机验证的可选模式，不修改默认起身、机器人标定、19499包或WTW上游。

`tests/test_tracking_startup.py`验证暂时卡滞后保持和恢复、永久卡滞超时、暂停时急停以及意外运动时硬限值。
简单滞后模型测试不代表机器人动力学、真实振动或行走验证。

## 本机实验结果
